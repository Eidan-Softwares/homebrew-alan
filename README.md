# Homebrew Tap for ALAN Programming Language

Official Homebrew tap for [ALAN](https://alan.eidansoftwares.in), the human-centric programming language engineered for computational clarity and native speed.

## Installation

```bash
brew tap Eidan-Softwares/alan
brew install alan
```

Or install in a single command:

```bash
brew install Eidan-Softwares/alan/alan
```

## Documentation

Full documentation, language specifications, tutorials, and binary packages are available at [alan.eidansoftwares.in](https://alan.eidansoftwares.in).
